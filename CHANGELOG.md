# Änderungen / Changelog

## 0.2.0 (2026-11-17), Beta

Arbeiten wie in Obsidian / Working like in Obsidian:

- **Dateien** (neues Modul im Dock): Ordnerbaum der verknüpften Ordner, auch leere Ordner. Neue Notiz, neuer Ordner, Umbenennen, Verschieben per Ziehen, Papierkorb nach `.trash` mit Rückgängig. Nur in Ordnern, für die du Bearbeiten eingeschaltet hast. / File tree with new note/folder, rename, drag-and-drop move, trash with undo; only in folders with editing on.
- **Tabs** für geöffnete Notizen (Strg+Tab, Strg+W, mittlere Maustaste) und **geteilte Ansicht** („Daneben anheften“). / Note tabs and split view.
- **Bilder** einfügen oder in den Editor ziehen. Sie landen im Anhang-Ordner aus `.obsidian/app.json`, `![[…]]` wird eingefügt. / Paste or drop images; saved where Obsidian puts attachments.
- **Lesezeichen**, **Hover-Vorschau** von `[[Links]]`, **Wort- und Zeichenzahl**. / Bookmarks, hover preview, word count.
- **Eigenschaften-Editor** für das Frontmatter und **PDF-Export** einer Notiz. / Properties editor and PDF export.
- **Testmodus**: Beispiel-Vault im eigenen Datenordner, ohne Verbindung zu Claude Code. / Test mode with an example vault.

## 0.1.0 (2026-11-17), Beta

Erste öffentliche Version: 3D-Gehirn der Notizen, Editor mit Versionen, Claude-Code-Live-Monitor mit Vorher/Nachher, Sitzungsnotizen, Lernbuch, Kontext-Server (MCP, nur lesend), .brain-Dateien, Geräte-Sync über den eigenen Cloud-Ordner, Schutz von Schlüsseldateien. / First public version.
